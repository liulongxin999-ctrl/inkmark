# 墨读 · AI 助手使用说明

> 墨读的 AI 助手是**可选功能，默认关闭**。
> 不配置它，墨读全程不会产生任何外部网络请求。

## 它能做什么

读书时遇到看不懂的地方，不用切出去搜：选中文字直接问，答案还能一键存成术语或笔记，
接进你已有的知识库和复习队列。

**四个入口**

| 在哪 | 怎么用 |
| --- | --- |
| 正文工具条 | 选中一段文字 → 点「问 AI」 |
| 术语悬停气泡 | 鼠标停在术语上，气泡里点「让 AI 讲讲这个」 |
| 命令面板 | `Ctrl + K` → 输入「问 AI」 |
| 侧栏 | 右侧栏点「AI」标签，直接开一条对话 |

**这些操作都只是把内容填进输入框，不会自动发送。** 发送必须由你按下去。

---

## 一、准备一个 API Key

墨读自己不提供模型，需要你用自己的账号。目前支持 **DeepSeek**。

1. 打开 <https://platform.deepseek.com> 注册并登录
2. 在「充值」里充一点钱（很少就够，见下面的费用说明）
3. 进「API Keys」→ 创建 → **复制保存**（这串 Key 只显示一次）

## 二、在墨读里开启

1. 打开墨读 → 左侧栏「设置」
2. 找到「**AI 助手（可选）**」区块
3. 把 Key 粘进「API Key」输入框 → 点「保存」
4. 右侧栏点「AI」，开始用

模型有两个选择：

- `deepseek-flash` —— 便宜、够用，还支持图片（**推荐**）
- `deepseek-v4-pro` —— 更强，贵约 3 倍

---

## 三、每次提问会发送什么

这是最需要了解的部分。

**会发送给 DeepSeek 的**

| 内容 | 说明 |
| --- | --- |
| 你选中的原文 | 就是你划出来的那一句 |
| 它所在的整个段落 | 为了让模型看懂上下文 |
| 书名和章节标题 | 例如「SJJG · 第 3 章」 |
| 相关术语的定义 | 仅限**这段文字里真的出现了**的术语，且可以在设置里关掉 |
| 你的问题 | 以及这个会话之前的问答 |

**永远不会发送的**

- 你的批注
- 你的笔记
- 术语的「我的理解」那一栏
- 其他书籍的内容
- 原始文件（PDF / EPUB 等）

**每次发送前都能看到**：输入框上方有一行「本次将发送：精简档 · 约 XXX 字」，
点「展开」可以看到**将要发出去的逐字原文**。

上下文可以调（设置 → 默认上下文）：

- **精简**（默认）：选段 ＋ 所在段落
- **本章**：再加上当前整章的完整内容

## 四、你的数据存在哪

| 数据 | 位置 | 会进 GitHub 吗 |
| --- | --- | --- |
| API Key | 项目目录下的 `ai.local.json` | 不会（已被忽略） |
| 对话历史 | 浏览器的 IndexedDB，随备份进 `backups/` | 不会 |
| 提问时发出去的内容 | 由 DeepSeek 按其隐私政策处理 | —— |

**页面本身读不回你的 Key。** 所有请求都经由墨读的本地服务转发，
浏览器里存不下、也看不到完整 Key。

### 想彻底关掉 AI

把「API Key」清空再保存，或者直接删掉项目目录下的 `ai.local.json`，然后重启墨读。
关掉之后，墨读和其它纯本地功能完全一样，不产生任何外部请求。

### 想删掉对话记录

设置 → AI 助手 → 「清空全部对话」。
单条删除：AI 面板的会话列表里，每条右侧有删除按钮。

---

## 五、花多少钱

按 token 计费，用你自己的账号。按一次典型的提问估算（发出约 2000 token，回答约 800 token）：

| 模型 | 一次提问 | 每天问 20 次，一个月 |
| --- | --- | --- |
| `deepseek-flash` | 约半分钱 | 约 ¥3 |
| `deepseek-v4-pro` | 约 2 分钱 | 约 ¥12 |

用「本章」档位会明显更贵（发送量可能大几十倍），只在真的需要通读全章时用。

## 六、遇到问题时

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 还没有连接 AI 助手 | 没配 Key | 按上面第二步配置 |
| 还没有配置 API Key | 同上 | 同上 |
| API Key 无效或已失效 | Key 填错，或已在官网删除 | 重新申请一个 |
| 账户余额不足 | DeepSeek 账户没钱了 | 去官网充值 |
| 请求太频繁，稍后再试 | 触发限流 | 等一会儿再问 |
| 连不上模型服务 | 断网，或接口地址填错了 | 检查网络和「接口地址」这一栏 |
| 这条回答没写完 | 网络中断，或你点了「停止」 | 已收到的内容会保留，可以重新问一次 |
| AI 助手需要本地服务 | 直接双击 `index.html` 打开的 | 请用「启动.bat」打开墨读 |

**AI 面板看不到？** 它只在阅读视图的右侧栏里。先打开一本书，再点右侧栏的「AI」。
